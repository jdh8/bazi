# 八字命盤

繁體中文、純靜態的八字排盤網頁。輸入出生日期、時間、性別，排出：

- 四柱：天干、地支、十神、藏干（附十神）、納音、十二長生、空亡
- 胎元、命宮、身宮（附納音）
- 起運時間、大運順逆、各步大運與流年（虛歲）

狀態存在網址，例如 `?d=1988-02-15&t=23:30&g=m&z=1`，可直接分享。

## 本機執行

需要 Node.js 22.12+（或 20.19+）。

```sh
npm ci
npm run dev
npm test
npm run build
```

推送到 `main` 後由 GitHub Actions 部署到 GitHub Pages。

## 曆法說明

- 排盤引擎為 [lunar-javascript](https://github.com/6tail/lunar-javascript) 1.7.7，本專案只做輸入、簡轉繁與呈現。
- 時間固定為台灣時間 UTC+8，不校正真太陽時、經度或歷史夏令時間。
- 子時可選「23:00 起算隔日」或「早晚子時」（晚子時 23:00–24:00 日柱不換）。
- 節氣交接時刻採用套件的壽星演算法，與日本國立天文台表最多相差約 2 分鐘；出生時間恰在節氣交接前後幾分鐘者，月柱（或年柱）可能與其他曆書不同。
- 支援西元 1801–2100 年。
